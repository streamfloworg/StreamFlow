🔍 How to Get Your Audio IDs

In StreamFlow, you can get audio IDs programmatically:

var audio = AppModel.Instance.Audios.First();
string audioId = audio.Id; // e.g., "AbC123De"
string uri = StreamFlowUri.Build(audioId);
Console.WriteLine(uri);

Consider adding a "Copy URI" button in your UI to make this easier!
